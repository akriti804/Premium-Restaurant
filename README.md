## 🛠 Installation

Clone the repository:

```bash
git clone https://github.com/akriti804/Premium-Restaurant.git
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
